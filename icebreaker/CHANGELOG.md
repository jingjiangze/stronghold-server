# 更新日志

## [未发布]

- **修复**：一些手机浏览器（如 OPPO/一加、小米、QQ 浏览器等内核较旧的浏览器）打开页面后，加载一直停在 30%。引擎的数据文件用了这些浏览器不认识的导入写法，整个页面的脚本都没有运行；现在服务器把这些数据改成普通脚本发送。浏览器实在太旧、页面无法启动时，加载画面会提示更新浏览器，不再一直卡住。
- **修复**：对局里引擎出错时，整个服务器会重启，同一台服务器上所有正在进行的对局都会断开，玩家重连时对局已经不存在，一直进不去。现在只结束出错的那一局，其他房间和对局照常进行。
- **修复**：IG-10 匪帮集会里，辐能源石虫出场后对局会卡住（它的普通攻击被错当成喷射罐的连续攻击，被击倒时的爆炸又缺少数值）。现在它按 PRTS 正常攻击；被击倒时在半径 1.25 内造成法术爆炸，并给场上的敌人 1 点能量。冰爆源石虫·α 的爆炸也补上了数值。
- **数据 mod**：服务器开服时读 `mods` 文件夹里的数据 mod（也可以用环境变量 `AUE_MODS_DIR` 或启动参数 `--mods` 指定），叠到官方内容上，启动日志列出每个 mod 是否加载、问题和冲突。玩家打开页面时从服务器取得同一份 mod，逐个核对文件；双方内容不一致时进不了对局。
  - mod 新加的干员出现在干员 box 和干员选择页里，用它借用外观的那名官方干员的头像、立绘、战斗模型和语音；mod 改过的干员按改过的数值显示和作战。
  - 装了 mod 的服务器，房间页顶栏和对局页左上角写明装了哪些 mod。
  - mod 新加的关卡暂时还没有大厅入口。mod 的写法和命令行工具（新建、检查、试跑、打包）见引擎的 docs/mods.md。

## [0.1.3] - 2026-10-20

- **干员选择页**：编队页的「快捷编队」和各列的干员卡现在打开原版样式的干员选择页（以前打开的是页面自己的 box 录入表）。
  - 列表：所有干员以游戏通用的干员卡排成两行，按稀有度显示底图、星级和光效；box 里有的按 box 的练度显示，没有的按满练度显示，选中并确认后以满练度加入 box。打开时这一顺位已有的干员排在最前。
  - 排序与筛选：按等级或稀有度排序，再点一次反过来；右侧的职业栏按职业筛选，选中职业后还能按分支筛选，职业栏可以收起；「稀有度筛选」从右边滑出星级列表，可以多选。
  - 选择：点卡片按顺序选入这一顺位，卡上标出序号，再点取消；另一顺位里的干员标着「编队内已选择」，选中后会移到这一顺位。「清空选择」清空，「确认」保存。
  - 详情：左侧显示最后点过的干员的代号、等级、属性、攻击范围，技能页签里有技能的名字、技力、触发方式、持续时间和说明，分支页签里有分支、特性和天赋。
  - 打开页面、展开筛选、收起职业栏、打开分支列表都播放原版的动画。
  - 编队页和准备阶段配置技能时，卡片改为先上下后左右排列，和原版一致。

- **设置面板**：对局页左侧的「画面」改名「设置」，面板换成和战斗界面一致的样式：分「画面」「声音」两组，每项的当前选项用白底标出，换选时白底滑过去；大小随画面缩放，手机横屏时两组左右并排；按 Esc 也能关闭。

- **修复部分手机上活动主界面的按钮不显示**：主界面地面的底纹和边缘是两块很大的图形，在地图的透视下浏览器要按屏幕分辨率给它们准备大量显存，显存紧张的手机上会把压在上面的界面丢掉（按钮、标志、底栏时有时无）。现在这两块各画在一张分辨率受限的画布上，画面不变，主界面所需的显存降到原来的四分之一以下；底纹照常滚动，也不会再引起忽明忽暗。

- **修复活动主界面忽明忽暗**：主界面地面下的平铺底纹在缓慢滚动，以前每一帧都让浏览器把整块地面重画一遍，显卡跟不上的电脑上地面会隔帧消失，整个画面忽明忽暗。现在滚动只移动已经画好的底纹，不再重画；较慢的电脑上主界面的帧率也明显提高（软件渲染下约为原来的三倍）。

- **多台服务器**：同一个服务可以开在几台服务器上，玩家就近连接。每台服务器各有自己的房间，房间号以所在服务器的编号开头；输入别的服务器的房间号时，页面会自动连到那台服务器加入，开局后的对战也在那台服务器上进行，刷新对战页面仍连回同一台。房间关闭后回到原来的服务器。用环境变量 `NCN_GAME_DIGIT`（本机编号 1–9）和 `NCN_GAME_PEERS`（每台服务器的「编号=域名」）设置；不设时和以前一样。

- **干员模组**：带模组时，模组追加的特性现在照原版生效，不再只有属性加成。例如无畏者、炮手、强攻手、要塞打被阻挡的敌人更痛，速射手打空中单位更痛，神射手、攻城手、轰击术师越远伤害越高，医师、守护者治疗低血量的友方更多；尖兵、铁卫阻挡时攻防提升，斗士、强攻手按生命值获得攻速或减伤，领主、收割者范围内敌人多时攻速提升，处决者、不屈者身边没有友方时变强；中坚术师、炮手、剑豪的无视防御和法抗，情报官、疗养师的嘲讽和抵抗；扩散术师、群愈师、塑灵术师的范围扩大，群愈师同时治疗四人；领主、驭法铁卫的附加法术伤害，各种元素损伤附加，巫役、伏击客、哨戒铁卫对范围内敌人的元素脆弱、减速和反隐；尖兵首次部署减费、处决者撤退多返费、召唤师的召唤物不占部署位、陷阱师的两倍伤害陷阱，无畏者、武者被击倒时不撤退一次，投掷手的三段伤害等。另外修正了带模组时部分干员的天赋被模组数据顶掉的问题（如早露、赫拉格带模组后第一天赋失效），链术师的模组也正确改变每次跳跃的伤害衰减。吟游者 Y 模组在技能期间让范围内的干员受到的伤害减少，维娜·维多利亚的 Y 模组让她和她的召唤物阻挡的敌人更容易受伤，艾拉的模组让她可以部署在近战位、陷阱可以放在远程位。雷狼龙S空爆的 X 模组按技能消耗的部署费用提升技能期间的攻击力，炼金师的 X 模组在自己的炼金单元在场时加快技力回复。推击手和钩索师的模组也做好了：推击手 Y 模组阻挡 2 个以上敌人时推力加一级，X 模组部署在远程位时返还一半费用；钩索师 X 模组让被拉动的敌人每被拉 1 格受到 800 点法术伤害，Y 模组拉远处（2.5 格以外）的敌人时力度加一级。链愈师（明椒、莎草）的模组把每次跳跃的治疗衰减改为 15%，白面鸮的模组扩大攻击范围（以前这两项没生效）。只在集成战略、生息演算里生效的模组在这里不起作用；伊内丝带 3 技能时 Y 模组改在第二次撤退时生效，还没有做。

- **傀儡师**：贝娜的替身攻击造成法术伤害，受到的物理和法术伤害按她的天赋减少。傀儡师换成替身时，画面上先播放切换的动作，之后是替身自己的待机和攻击动作，换回本体时播放换回的动作（以前一直是本体的动作）。

- **持续时间无限的技能**：写着「持续时间无限」的技能开启后一直生效，直到手动关闭或干员撤退。以前这些技能一开就结束、加成不生效（如拉普兰德、耀骑士临光、孑的技能），或者只作用于一次攻击（如铃兰、灰烬、史尔特尔的技能）。史尔特尔三技能开启时回满生命，生命上限 +5000，之后生命流失逐渐加快，60 秒后达到每秒 20% 最大生命。

- **鼓舞**：空、海蒂、浊心斯卡蒂、魔王、三角初华的技能现在让攻击范围内的友方获得鼓舞，按吟游者自己的攻击力、防御力或生命上限的一定比例加成。同一项属性有几个鼓舞时只取比例最高的一个，吟游者自己不受鼓舞。以前这些比例被错加到吟游者自己身上，友方什么也拿不到，比如空的「战斗之歌」让她自己的攻击力和回血几乎翻倍。海蒂的技能会改变范围内友方的阻挡数。吟游者不攻击，现在她们的自动技能技力满了就开启。

- **佣兵**：雷狼龙S空爆、哈蒂娅的技能开启时消耗说明里写的部署费用，费用不够时不能开启，技能图标也不显示可以发动。以前开技能反而会获得这些费用。技能期间再消耗费用的「装备应变」还没有做。

- **炼金师**：锡人、旅骨、引星棘刺的一、二技能现在会投出炼金单元，以前这些技能只是一次加倍的普通攻击。
  - 落点：对敌人的投向攻击范围内的敌人，没有敌人时投到正前方最远的格子；引星棘刺一技能投给攻击范围内生命比例最低的友方。
  - 效果：炼金单元在原地停留技能写明的时间，每秒对范围内的地面敌人造成法术伤害，并按技能给敌人虚弱、减速或减少受到的治疗，给友方回复生命或增加防御。引星棘刺二技能的炼金单元会慢慢远离她并逐渐扩大。干员撤退后，炼金单元仍然留在场上。
  - 天赋：锡人的炼金单元伤害更高；旅骨的炼金单元里敌人的命中率降低，重型敌人降得更多；引星棘刺攻击范围内有别的干员时，她的炼金单元持续更久。引星棘刺在场时，全场友方攻速提高、敌方攻速降低，站在长直道路上的单位效果翻倍。
  - 画面：按原版播放投掷的拖尾和落地后的特效；锡人、旅骨的普通攻击也有了原版特效。
  - 引星棘刺三技能（向几名干员投掷、连成区域）还没有做。

- **技能的命中效果**：技能说明里写的这些效果现在都会生效，以前大多被忽略：
  - 命中时的异常：沉默（如孑、缄默德克萨斯、蚀清的「失去特殊能力」）、寒冷（极光）、沉睡（埃拉托），以及按几率的沉睡、晕眩（缇缇、梅）。
  - 命中时的限时减益：如流星、陨星降低目标防御，霜叶、狮蝎、安哲拉、食铁兽减速，慑砂降低攻速；同一干员再次命中会重新计时。
  - 攻击时回复自己的生命（火神、泥岩、炎客），技能期间按最大生命回血（蛇屠箱、铸铁、宴、乌有、夜半、缪尔赛思）。
  - 下次攻击附带的元素损伤（塑心、凛视、伯塔尼、波卜）。
  - 推和拉：崖心、暗索、雪雉、杏仁、歌蕾蒂娅等的「拖拽至面前」会把敌人拉到面前，阿消、食铁兽、见行者、可颂等会把敌人推开。拉的距离按原版公式算，和 PRTS 列出的距离一致。
  - 被动技能里写的命中效果，对每次攻击都生效。
  - 另外修正了一个读取问题：说明文字里的换行以前会导致紧挨着换行的那句没被读到，影响了不少技能。

- **干员天赋**：更多干员的天赋照原版生效。以前只有属性加成、按职业或势力的在场加成、攻击范围内的加成、几率强化攻击、按在场时间的加成和部署时的效果这几类，现在又加上：
  - 常驻效果：无视防御和法抗（送葬人、迷迭香、耀骑士临光、史尔特尔、Pith），闪避（食铁兽、暗索、杰克、12F、杜林；夜魔带一技能时获得闪避，带二技能时获得攻击力），攻击距离（战车），造成和受到的物理伤害（埃癸斯），受到的元素损伤（菲莱），按最大生命值回血（维荻、绮良）。
  - 有条件的加成：阻挡或未阻挡敌人时（崖心、火哨、晓歌、布洛卡、讯使），攻击范围内敌人或其他干员够多时（领主·Sharp、佩德洛、协律），范围内有残血敌人或凋亡损伤爆发的敌人时（水月、折光），身边四格没有敌人或只有一个敌人时（异客、Misery），身边没有友方时（清道夫；绮良回血翻倍），技能未开启时（蜜蜡回血）。
  - 对特定敌人更强：使用远程武器的敌人（守林人），被阻挡或未被阻挡的敌人（和弦、惊蛰、裁度、燧石），萨卡兹和感染生物（熔泉、孑），空中单位（流星、巡林者），残血或满血的敌人（苦艾、戴菲恩），轻型或重型敌人（歌蕾蒂娅、见行者），战栗的敌人（锏）。
  - 攻击附带：几率束缚或停顿（仇白、伊桑、承曦格雷伊、格雷伊），沉默（拉普兰德；天空盒对每个敌人第一次），战栗（维娜·维多利亚，对每个敌人第一次），法术脆弱（濯尘芙蓉，焰影苇草的灼痕），降低法抗（夜烟、暮落），附加法术伤害（麒麟R夜刀），同时攻击两个目标（初雪）。
  - 几率触发：陨星的攻击力加成、芙兰卡无视防御、慕斯和 Misery 的二连击、艾拉的强力一击。
  - 全场效果：安洁莉娜提高全场攻速，白面鸮提高全场技力回复（和莫斯提马这类「同类效果取最高」的只取最高的一个），临光提高全场的治疗效果，格拉尼、焰尾让先锋、卡西米尔干员获得闪避；海蒂按所带技能给范围内友方加攻击力或防御力。
  - 叠加：炎客、柏喙、羽毛笔每击杀一个敌人叠加一层，夕和小自在的击杀都算；铸铁、奥达、水灯心在击杀或造成伤害够次数后获得加成；信仰搅拌机每次造成伤害短时叠加防御和攻速；缄默德克萨斯每次部署后、第一次击倒敌人之前攻速提高、受到的伤害降低。
  - 技力：阿米娅攻击和击杀时额外回复技力；塞雷娅、Touch 治疗时给被治疗的干员技力；华法琳、Touch 在攻击范围内有敌人或干员倒下时回复技力；雷蛇受到攻击时给自己和身边一名友方技力；空的技能结束后有几率回复一半技力；佩佩技能期间击倒的敌人在技能结束时换成技力。
  - 坚忍：摩根、火龙S黑角、赤冬、宴损失的生命越多加成越高，损失七成时达到最高。
  - 持续伤害：蓝毒的中毒、深巡的攻击和奥斯塔对未被阻挡敌人的流血，每秒造成法术伤害。
  - 和技能有关的：卡夫卡、缄默德克萨斯在被动技能期间攻击力提升（卡夫卡还不阻挡敌人、获得迷彩），子月未开启技能时获得迷彩、开启后攻击更快，郁金香在第二次开启技能之前技力回复更快，玫拉从第二次开启技能起技能期间伤害提高，折桠技能结束时回复六成生命；安洁莉娜技能未开启时全场每秒回血，烈夏开启技能时乌萨斯学生自治团干员攻速提高，微风开启技能时医疗和辅助干员获得抵抗。

- **比赛风格**：基础、驻场、游走、攻坚、支援，各自的增益和代价只作用于选它的玩家，并带一张携带物卡（赛场啦啦队、护具分发员、混乱烟花箱、猛兽能量饮料、喷射汽水机）。
- **干员 box 与存档**：手动录入干员的精英化、等级、潜能、信赖、技能等级和模组阶段（按每名干员的上限），存在本机浏览器里，可以导出、导入为文本；「随机填满常规队」一键填入 20 名满练度的六星。
- **对局**：一局两个阶段，帧同步、服务器复算；72 名六星干员按 Stronghold Protocol 的 kit 作战，其他干员按引擎自己的实现；全部 461 名干员都能上场。
- **原版的战斗外界面**：活动主界面（3D 场景，地上走动的人、楼顶的横幅环）、创建与加入房间、赛前流程的每一步、赛前编队与比赛风格、结算、断线提示与对话框，动画、界面粒子和界面音效按原版；房间里放活动的《罗德行进曲》。
- **画面与声音**：真 3D 战场与 Spine 模型、原样式的战斗界面；合作关卡用各自场景的地图主题，四周带场景里的装饰；原版的战斗音效和各关卡自己的战斗曲；帧率上限、清晰度、攻击特效、音乐、音效和语音的音量、配音可在设置里调。普通攻击和命中音效仍然空着。
- **字体**：界面的宽体与方体字换成 OFL 授权的 Montserrat 和 Chakra Petch，中文用 Noto Sans SC。
- **干员语音**：干员在部署、部署后第一次接敌、技能开启、被选中时说话，开场由编队第一名干员说「行动出发」。一次只说一句，优先级、冷却和交叉淡化都按游戏数据。配音默认按游戏数据（大多是日语，联动干员是联动配音），也可以选素材里有的中文-普通话等配音。
- **局域网**：`node packages/server/src/main.js --host 0.0.0.0`，另一台电脑打开 `http://<局域网 IP>:8700/`；局域网地址打开的页面同样可用（不依赖只在 HTTPS 下才有的浏览器功能）。
- **发布包**：Releases 附完整包（程序、运行依赖、素材和干员 kit，解压即可开服）和素材包，各带每个文件的 sha256 清单；素材的使用条件见 NOTICE。
- 引擎：[明日方舟通用引擎](https://github.com/ArknightsDevs/Arknights-Universal-Engine) v0.1.0，协议第 8 版。
