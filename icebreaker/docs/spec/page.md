# 页面

### 页面-1 画面设置

画面的开销由玩家选择（引擎 ADR 0059），对局页左侧的「设置」标签打开设置面板，选择立即生效，并保存在本机：

| 设置 | 选项 | 默认 |
|---|---|---|
| 帧率上限 | 跟随屏幕、144、120、60、30 | 跟随屏幕 |
| 清晰度 | 100%、75%、50%（画布像素比相对设备像素比，引擎 渲染-15） | 100% |
| 攻击特效 | 开、关（引擎 渲染-15） | 开 |
| 显示帧率 | 关、开（左下角显示最近一秒画了多少帧） | 关 |
| 音乐 | 100%、50%、关（页面-4） | 100% |
| 音效 | 100%、50%、关（页面-4） | 100% |
| 语音 | 100%、50%、关（页面-4） | 100% |
| 配音 | 默认，以及素材的语音里有的中文-普通话、日语、英语、韩语（页面-4）；素材里没有语音时不显示这一项 | 默认 |

- **帧率上限**：有上限时，屏幕的每次刷新只在距上一次绘制的时间槽满一个间隔（1000 ÷ 上限 毫秒）时绘制，早到 1.5 毫秒以内也算到了；间隔两倍以上没有绘制时，时间槽从这一帧重新开始。
- **保存**：本机存不了时（隐私模式等），选择只在这一页有效；存的内容不完整或有误时，那一项用默认值。
- 设置只影响画面，战斗照常每秒 30 帧（引擎 时间-1）。
- **面板**：分「画面」（帧率上限、清晰度、攻击特效、显示帧率）和「声音」（音乐、音效、语音、配音）两组，每项的选项排成一条，选中的一项用白底标出，换选时白底滑过去；样式随战斗界面（深灰半透明底，右上角切角，左边一条活动的青绿色线），大小随画面缩放；页面矮的时候（手机横屏）两组左右并排。再点标签或按 Esc 关闭。系统要求减少动态效果时不播放滑动。

- 来源：设计决定，见引擎 [ADR 0059](https://github.com/ArknightsDevs/Arknights-Universal-Engine/blob/main/docs/adr/0059-player-chosen-performance.md)；面板的青绿色取活动赛季封面的颜色（INF-0017）

### 页面-2 本地存档与 box 录入

房间页下方是玩家的干员 box、常规队和比赛风格（房间-3），连同玩家的名片（房间-1）存在本机浏览器里：

- **名片**：昵称（最多 16 个字）、代号（4 位数字）、助理干员与它的立绘（精英一、精英二）、头像，各一个输入框或选择框，下面写着房间里会显示的样子；从 box 删除的干员也离开名片，回到默认。

- **录入**：输入干员名加入 box，起始为满练度：最高的精英化与等级、已开放技能的最高等级、潜能 1、信赖 100%、模组未解锁。之后可以在这名干员的上限之内修改精英化、等级、潜能（1 至 1 + 潜能提升次数）、信赖（0–200%）、各技能等级和各模组阶段。
- **上限**：技能随精英化开放；技能等级在精英 0 最高 4 级，精英 1 最高 7 级，精英 2 可专精到 3 级（技能自己的等级数更少时以它为准）。模组在精英化和等级达到它的要求后才能升到 1–3 级。改动精英化或等级后，超出上限的项降到上限。
- **常规队**：box 里的干员可以放进高顺位或低顺位，或移出常规队；某一边满了时不能再放（房间-3 的人数）。从 box 删除的干员也离开常规队。「随机填满常规队」随机挑选还不在常规队里的六星干员，以满练度（精英化与等级到顶，开放的技能和模组到最高）补到高顺位 10 名、合计 20 名。
- **保存**：每次改动立即保存在本机。存不了时（隐私模式等），改动只在这一页有效，页面会提示。读到的存档不完整或有误时，原文另存一份，换成空存档。
- **比赛风格**：五种风格各一个按钮，选中的风格下面写着它的增益、代价和携带物的效果。没有记下风格的存档按基础处理。
- **导出与导入**：存档可以导出为一段文本，再从文本导入；不是合格存档的文本不会导入，页面说明原因。

- 来源：设计决定（计划 6.2，问答 7、8：存档默认在本地，box 手动录入）；技能等级的开放条件取自游戏数据 `character_table.json` 的 `allSkillLvlup[].unlockCond`（2–4 级 PHASE_0、5–7 级 PHASE_1，全部 439 名干员相同）与 `skills[].levelUpCostCond[].unlockCond`（专精都要 PHASE_2）；技能与模组的开放条件、等级上限、潜能提升次数取自引擎的干员训练数据（引擎 干员-1）

### 页面-3 局域网打开的页面

经局域网地址（如 `http://192.168.1.2:8700/`）打开的页面不是安全上下文，只能用不需要安全上下文的浏览器功能：会话密钥用 `crypto.getRandomValues` 生成，不用 `crypto.randomUUID`；复制邀请文字由玩家自己选中复制，不用剪贴板接口。

- 来源：设计决定；安全上下文的限制见 [MDN「Secure contexts」](https://developer.mozilla.org/en-US/docs/Web/Security/Secure_Contexts/features_restricted_to_secure_contexts)（`crypto.randomUUID`、`navigator.clipboard` 只在安全上下文可用）

### 页面-4 声音

对局页按引擎的音频规则出声（引擎 音频-1…6）：

- 素材里有音频索引（`audio/index.json`）时才有声音；没有时整页静音，对局照常进行。
- 浏览器要等玩家第一次点按或按键后才让页面出声，所以在那之前听不到声音。
- 每帧的表现事件按 音频-2 播放音效；战斗从第 0 帧开始时播放关卡的音乐（音频-3），战斗结束时淡出。
- 服务器的控制消息（引擎 同步-7、同步-8）里，协作者申请暂停时播 `battle.ON_COOPERATE_PAUSE_CONFIRM`；协作者打开二倍速、而自己还没打开时播 `battle.ON_COOPERATE_SPEED_REQUEST`。
- 素材里有语音索引（`voice/index.json`）时干员说话（引擎 音频-4…6）：
  - 拿到这一局的内容后，先加载自己座位的干员按当前配音的全部台词。
  - 每帧的表现事件按 音频-5 说话：部署、部署后第一次攻击敌人、技能开启。
  - 页面在战斗开始前就打开时，战斗从第 0 帧开始的同时，由自己编队里第一名有台词的干员说「行动出发」。战斗开始后才打开（重连）的页面不说。
  - 原样式界面里，按下一张能用的手牌，或点开场上自己的干员的菜单，就是选中这名干员，说「选中干员」。
- 音乐、音效、语音的音量由画面设置里的「音乐」「音效」「语音」决定（页面-1）。
- 配音由画面设置里的「配音」决定：「默认」是每名干员自己的默认配音，选了语言而这名干员没有时也用默认配音（引擎 音频-4）。

- 来源：设计决定（引擎 ADR 0024、ADR 0061，规划问答 Q69）；配音的选项和名字：数据 charword_table.json `voiceLangTypeDict`；语音的时机为推断，同引擎 INF-0172；浏览器的自动播放限制见 [MDN「Autoplay guide for media and Web Audio APIs」](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)；协作者申请时的提示音为推断，同引擎 INF-0169

### 页面-5 房间页的图标和音乐

素材里有房间页的图集（`ui/room/index.json`）时，房间页用活动的图标；没有时只显示文字，其余照常：

- **比赛风格**：每种风格的图标按活动表里它的图标编号取（基础 `buff_icon_basic`、驻场 `buff_icon_anchoring`、游走 `buff_icon_roaming`、攻坚 `buff_icon_offensive`、支援 `buff_icon_supportive`），颜色用它的主题色。
  - 选风格的按钮带小图标（`_tiny`）。
  - 选中的风格在说明旁边显示完整的图标。
  - 项目确认时自己的风格，组建上场阵容时双方的风格，前面都带小图标。
- **项目的模式**：项目说明前显示模式名「常规项目」，用活动表里模式的颜色，前面是这种模式的图标。

素材的音频索引里有音乐库 `sys.ON_MULTIV3_LOADED`（「促融共竞」主界面的《罗德行进曲》）时，房间页播放它：

- 先播前奏，前奏结束时接上循环段，一直循环。音量是这个库的音量乘以玩家的音乐音量。
- 浏览器要等玩家第一次点按或按键后才让页面出声，所以音乐从那时开始。
- 页面右上角的「音乐」按钮在 100%、50%、关 之间切换。它就是画面设置里的「音乐」（页面-1），两个页面共用这一项。
- 比赛开始、页面转到对局页时，音乐按库的交叉淡化秒数淡出，然后才转页面。

- 来源：数据：activity_table.json `MULTIPLAY_V3/act1multi` 的 `squadEffectList[]`（iconId、themeColor）、`mapModeDataDict.NORMAL`（name「常规项目」、color d2284b）；audio_data.json `bgmBanks` 的 `sys.ON_MULTIV3_LOADED`（m_sys_act1multi_intro、m_sys_act1multi_loop、volume 1、crossfade 1）；[PRTS「音乐鉴赏/游戏内音乐一览」oldid=440958](https://prts.wiki/index.php?title=%E9%9F%B3%E4%B9%90%E9%89%B4%E8%B5%8F/%E6%B8%B8%E6%88%8F%E5%86%85%E9%9F%B3%E4%B9%90%E4%B8%80%E8%A7%88&oldid=440958)：sys_act1multi 为「促融共竞#1 OST - 罗德行进曲」「「促融共竞」主界面BGM」；图标取自素材的图集；模式图标的对应、各种图标用在哪里为推断 INF-0005；音乐在房间页播放、离开时淡出再转页面为推断 INF-0006

### 页面-6 原版的组队参赛界面

素材里有战斗外界面包（`ui/lobby.json`，引擎 ADR 0063）时，房间页整页画原版的促融共竞界面，页面逻辑仍是 房间-1…6。没有界面包，或者地址带 `?html` 时，用页面自己的 HTML 房间。各房间状态对应的原版界面：

| 房间的状态 | 原版界面 |
|---|---|
| 不在房间里 | 活动主界面：「组队参加」打开房间面板，「发起！」创建房间，「加入！」输入房间编号（或整段邀请文字）加入（房间-1）；「编队」打开编队页 |
| 编队页 | 常规队的高顺位、低顺位两列干员（每列两行，先上下后左右）；「更换」打开比赛风格的选择，「确认修改」保存风格（房间-3）；两个「快捷编队」和各列的干员卡打开这一顺位的干员选择页（页面-9） |
| 项目调整 | 备赛页的项目选择面板：房主「切换地图」打开关卡列表选项目，协作者准备后「进入备赛」；参加者「准备就绪」「取消准备」；房间编号与「复制」（复制邀请文字）（房间-2） |
| 项目确认 | 关卡确认：关卡详情（代号、模式与级别、关卡图，关卡表里这关的描述，其中游戏的标记按游戏的富文本样式着色）、关卡目标（活动表给这关的三项任务，依次以箭头相连，长的分两行；任务的活动代币奖励平台不发，不显示）、协作者是否已确认；「我确认好了」交出常规队和比赛风格（房间-2、房间-3）；双方都确认后是开赛展示：罗德岛标志拼出，接着「比赛启动」显示双方的名片和比赛风格，停一会儿后退场，进入高顺位干员协调或组建上场阵容 |
| 高顺位干员协调 | 干员协调面板：轮到自己时，剩下的干员卡和「跳过 让队友先选」；「查看预备阵容」看自己已经保留的干员（房间-4） |
| 组建上场阵容 | 先展示随机分配给自己的干员；然后三步：选上场阵容（6–10 名），选技能和模组（「技能」「模组」两个页签：技能显示图标和等级或专精；模组显示类型图标、类型名与额外类型标记、等级，box 里没解锁的上锁），提交阵容后看双方的阵容（连同各自选的技能和模组）并「准备就绪」「取消准备」；「上一步」回到前一步（房间-5、房间-6） |
| 比赛开始 | 倒计时 3-2-1 压在检查阵容上，接着白框收拢到罗德岛标志；标志停住后画面转黑，进入对局页 |
| 比赛结束、回到房间页 | 结算第一页：自己的助理干员立绘（向右、向下渐隐），关卡名和级别；得到的嘉奖印章数作为评级的星数，各阶段是否得到印章；「下一步」进入第二页：双方的助理干员立绘和名片，关卡代号、级别、星数和评语（1–3 星为「稳扎稳打」「崭露头角」「统治赛场」），比赛结束的时间；对方名片上的点赞按钮点一次就给对方点赞（房间-6），自己被点赞时自己名片上出现点赞标记；「返回房间」回到房间，「返回主页」离开房间。背景是战斗最后一帧的模糊画面 |

- 备赛页的顶栏显示当前步骤的倒计时（项目确认 30 秒、协调每次 20 秒、组建阵容 60 秒）。剩余时间不超过活动表的 `hintTime`（10、3、5 秒）时换成警示样式。顶栏还显示关卡和级别、离开按钮。
- 侧栏显示双方：名字，比赛风格（公开以后），准备或确认的标记，协作者掉线。房主在项目调整时可以「请离房间」。侧栏还显示房间的剩余时间（「后赛事自动关闭」）。项目调整和检查阵容用完整的侧栏（离开与「上一步」在侧栏上，顶栏的关卡信息让到侧栏右边），高顺位干员协调、选择上场干员和配置技能模组用精简的（「上一步」在顶栏），项目确认时不显示侧栏；切换时侧栏滑入，玩家准备好时红色标记描出；开赛展示时侧栏让开。
- 进入协调时，横幅显示先手或后手选择；不需要协调就进入组建阵容时，显示「无需协调 双方阵容无重叠」，停一会儿后用横幅的切换片段换成「组建上场阵容」再退场；从协调进入组建阵容时，显示「组建上场阵容」。
- 离开房间、请离协作者先在确认对话框里确认。提示显示在通知框里；协作者加入或退出、项目变更、复制房间编号的提示文字取自活动表 `constToastData`。
- 没有对应系统的入口不显示（引擎 ADR 0063）：手册、里程碑、奖励、奖章、好友邀请。
- 快速匹配的进出：活动主界面点「快速匹配」时，先播放主界面转入匹配的片段（镜头推近，各面板在遮罩下淡出），再打开匹配页。匹配页上，常规项目选中了至少一个级别时，它的标题栏随它的切换片段滑入，一个都没选时倒放滑出；身份列表打开和关上时，按控制器给的时长（0.3 秒）淡入淡出，身份按钮用它的切换片段反向淡出、淡入；打开互选模式时，互选特效按控制器的时长（0.25 秒）淡入并播放它的入场片段，关上时淡出。
- 原版里由游戏另外提供的内容：干员卡的半身像用游戏的干员半身像（精英二起用精二的，没有时用头像铺满窗口）；职业、精英化的图标用战斗界面包里的；稀有度的星条和潜能标记用游戏通用的（界面包随附），星条用各稀有度同宽、星星靠左排的那一套（和原版截图一致：不论几星都从名字下方的左端排起），按卡片节点的颜色染色，潜能标记从第二潜能起显示。高顺位干员协调的卡片不显示技能与模组栏。开赛展示的名片用默认的罗德岛名片皮肤（按皮肤图自己的大小放进皮肤位），称号是没有选过称号时的「平凡的博士」（活动表称号里排在最前的前半与后半），名字写成「昵称#代号」，头像是玩家名片上的头像（房间-1）；没有的等级、ID 不显示。备赛页完整侧栏上的玩家同样显示「昵称#代号」、称号与头像，比赛风格用带名称的完整图标。备赛页顶栏和完整侧栏上显示到服务器的延迟「当前延迟 xx ms」（活动表的文字与颜色，每 2 秒测一次）。页面放入游戏通用的顶部菜单（组队面板、编队页、比赛风格选择有返回和首页，选关列表只有返回）和底部滚动栏（活动首页、结算）。玩家称号和等级不显示。
- 赛季标志：原版按赛季填入的标志位放本赛季（促融共竞#1）的标志：活动首页左上是横排的完整标志；标题动画的赛季封面上是标志的图形（下面另有活动自己的 Rhodes Island Icebreaker Games 字样）；底部滚动栏左端是很淡的图形，压在滚动栏底下；开赛展示右上（LIVE 旁）是图形与下面一行小字样；关卡详情的左下是灰色的图形和右上的小字样。素材里没有本赛季的标志时这些位置不显示。
- 助战立绘：开赛展示左右两侧显示双方名片上的助理干员的立绘（房间-1），用玩家选的精英一或精英二立绘；立绘按游戏里每张立绘自己的位置与大小放进立绘位，被两侧斜切的遮罩裁出。素材里没有这名干员的立绘时那一侧空着。
- 主界面的 3D 场景：素材里有它的 3D 索引（`ui/lobby3d/index.json`）时，由引擎画在主界面后面（引擎 渲染-17），跟着主界面的片段走（进房间面板时镜头推近、返回时拉远），地面画布按镜头贴到地上（不再另外裁掉镜头后面的部分，浏览器自己不画它）；从后往前依次是天空的颜色、地面、模型、主界面。没有索引时不画这一部分。
- 标题动画：打开房间页后第一次显示活动主界面时，主界面的入场片段从头播放，前 2.28 秒是标题动画（白底上的 RHODES ISLAND 与罗德岛标志、三色环线，ICEBREAKER / GAME 两行，色块扫过，赛季封面铺开再滑走）；等主界面的 3D 场景和界面粒子准备好（最多 6 秒）再开始，其间停在第一帧的白屏上。两行文字和封面颜色由游戏运行时填入，按原版录像填写；封面上的赛季标志见下面的「赛季标志」。之后再回到主界面时片段从 2.28 秒开始，不再播标题。
- 界面的粒子：素材里有界面特效包（`ui/lobbyfx.json`）时，各界面里的粒子节点显示时播它们的特效（引擎 渲染-18）：二维界面上的画在页面上方一层，被后画的一整块不透明的纯色界面盖住时不画（标题动画的赛季封面盖着主界面时，组队参加按钮的波浪不露出来），只画在最近的遮罩里，旁边有写模板的图片时（组队参加按钮的波浪只画在它的圆角底图里）再裁到这张图的矩形内；主界面地面上的（走动的人、楼顶上方的横幅环）画进 3D 场景。没有特效包时不画。
- 对局页加载时，先打开原样式战斗界面的合作开始面板作为加载画面（「OPERATION」、关卡代号与名称，引擎 界面-21），场地、模型和特效在它后面加载；页面底色为黑色，与房间页最后转黑相接。从房间页开赛时，房间页把关卡代号与名称留给对局页（只用一次），对局页一打开就显示加载画面，不等收到对局内容；重新打开的页面没有它，照常等对局内容。
- 对局页在比赛结束时记下结果（胜负、关卡、各阶段的印章、结束的时间）和战场最后一帧的缩小模糊图，回到房间页时显示一次结算。
- 备赛页顶栏的「查看地图」打开关卡详情对话框（与项目确认里的关卡详情相同），点关闭或对话框外关闭。
- 页面保留自己的工具：返回、干员 box、音乐音量、连接状态。

- 来源：数据：activity_table.json `MULTIPLAY_V3/act1multi` 的 `selectStepDataList[]`（time、hintTime）、`constToastData`、`mapDataDict` 的 `previewIconId`（关卡图）、`squadEffectList[]`；界面、节点和动画片段取自界面包（引擎 ADR 0063）；各房间状态对应的界面与它们的文字、侧栏的样式、标记和横幅的时机为推断 INF-0007；干员卡用头像铺满立绘窗口、卡片颜色和结算的星数为推断 INF-0008；没有矩形的普通节点铺满父节点为推断 INF-0009；赛前编队页每个顺位一列的宽度为推断 INF-0010；协调页的卡片不显示技能栏为推断 INF-0011，潜能标记为推断 INF-0012，侧栏在各步骤的样式为推断 INF-0013，名片皮肤、顶部菜单与底部滚动栏为推断 INF-0014；开赛展示和倒计时的先后按原版录像（哔哩哔哩 BV1zGsezzEjm 第 1P），展示的停留与倒计时转黑的时刻为推断 INF-0015；关卡目标的任务取自活动表 `mapDataDict` 的 `missionIdList` 与 `targetMissionDataDict` 的 `description`，关卡描述取自 stage_table.json 的 `description` 与 gamedata_const.json 的 `richTextStyles`，不显示任务的奖励为推断 INF-0016；标题动画的两行文字、赛季封面的颜色和只在第一次进入时播放为推断 INF-0017；赛季标志取自 PRTS「文件:图标 促融共竞01.png」（revid 338508，即活动首页标志位 468 × 139 的那张），其余标志位的样子、助战干员的选法为推断 INF-0018；立绘的放法按原版录像核对过（第 1P 的「比赛启动」里队友的立绘是斩业星熊的精英一立绘，按它自己的位置与大小放进立绘位后与录像的相关系数为 0.88，换用别的位置都对不上）；地面不裁剪的依据是在 GPU 上逐帧录屏比较：裁剪时整块地面隔帧消失（页面闪烁），不裁剪时没有消失也没有画错

### 页面-7 手机

两个页面（组队参赛和对局）在手机上横屏显示：

- **竖着拿**：触屏设备竖着拿时，整个页面顺时针转 90° 横过来显示，按屏幕的长边铺满；页面和引擎读到的指针位置、元素位置和窗口大小都换算到转过来的画面里，所以点按、拖卡部署、拖方向、拖标记、滑动列表都和横着拿时一样。横着拿时和带鼠标的设备不转。
- **触屏手势**：组队参赛界面（原版界面时）和对局页上，浏览器自己的缩放、整页滚动、长按菜单和点击高亮都关掉，手势只给游戏；干员 box 面板仍可上下滚动。
- **全屏**：浏览器支持网页全屏时（如 Android 的 Chrome），触屏设备上显示「全屏」按钮（组队参赛页在底部的小工具栏里，对局页在「设置」标签下面），点一下进入或退出全屏；iPhone 的 Safari 不支持网页全屏，不显示。
- **页面自己的工具栏**：触屏设备上组队参赛页底部的工具栏（干员 box、音乐、全屏、连接状态）字号更小、半透明，少挡原版的底栏。
- 没有 Web Audio 的浏览器不出声，页面照常运行。

- 来源：设计决定（维护者要求做移动端适配；做法与同一站点上的争锋频道相同：竖屏时整个画面转成横屏）

### 页面-8 加载画面

- 两个页面从第一次绘制起显示加载画面，直到页面接手：先只是一层与页面同色的暗色遮罩（#1b1d21）；0.6 秒后还在载入时，淡入活动的加载图（常规项目的；从房间进入堡垒守御的对局时用堡垒守御的，按原版拉伸成 16:9 铺满屏幕）和等待条。0.6 秒内载入完的页面只见暗色遮罩淡出，页面之间不闪出加载图。
- 屏幕下方是原版备赛页「等待重新加入通讯线路」面板的那条等待条：底部的暗色渐变，中间 63 参考像素高（战斗外界面包的 1280 × 720 参考像素）的条盖在加载图里模糊的新闻条上——两侧是半透明橙色斜纹，中间 659 参考像素宽的黑色底板上，左边 LATEST NEWS 标签，中间转动的循环箭头和橙色的状态文字（如「正在载入大厅界面」）与百分比，右边活动的小标志。原版的图标、斜纹和渐变到了以后换上原版的。
- 进度：先按服务器写进页面的预加载数（站点-4）算模块到了多少，占前 30%；之后由页面报告：载入界面包和它的精灵图、连接对局、载入本局的模型、贴图、地图拼件与特效（站点-5）。斜纹底下的橙色从左往右按进度铺满。
- 等待条按原版面板的入场片段出现（0.75 秒：橙色从两端向中间长满，再向中间收拢，露出等待条；暗色渐变 0.33 秒淡入）。
- 接手：大厅页在大厅的入口界面（或没有界面包时页面自己的房间）出现时，对局页在原版的开始面板（引擎 界面-21）出现时、没有开始面板时在对局开始时，加载画面在 0.3 秒里淡出。载入对局失败时换成原版的警告图标和原因，「刷新页面重试」，不再消失。
- 页面的脚本没能启动——浏览器太旧、读不懂页面用到的语法，或脚本没有载入——时，页面还没报告过任何一步（进度停在模块的 30%），加载画面换成警告图标和该做什么：语法错误时「浏览器版本太旧，页面没能启动。请更新浏览器，或换用最新的 Chrome、Edge 后刷新」，其他错误时「页面脚本没能载入，请刷新页面重试」，不再消失。页面报告过一步之后的错误由页面自己处理。
- 偏好减少动态效果时没有入场片段、转动和淡出。

- 来源：活动的加载图（`loading_loading_MULTIV3_normal`、`_defence`）和备赛页断线面板的等待条、图标、颜色与入场片段取自界面包；两者放在一起作为加载画面、等待条盖在加载图的新闻条上、进度的画法、出现和接手的时机为推断 INF-0026

### 页面-9 干员选择页

编队页的「快捷编队」（或某一列的干员卡）打开原版的干员选择页，为常规队的这一顺位挑干员（高顺位最多 10 名，低顺位最多 20 名，房间-3）。界面、节点和片段取自界面包里主游戏的干员选择页、排序栏、排序筛选面板和职业筛选，干员卡用主游戏通用的干员卡。

- **列表**：所有有训练数据的干员，每张卡显示稀有度对应的底图、光效、上下框和星级，职业图标，半身像，等级（满级时经验环填满），精英化图标，第二潜能起的潜能标记和名字。box 里有的干员按 box 里的练度显示，没有的按它加入 box 时的满练度（页面-2）显示。卡片排成两行，先上下后左右，横向滚动；打开时这一顺位已有的干员排在最前。
- **排序**：「等级」（精英化阶段，其次等级）或「稀有度」，另一项作为次序；再点一次同一项改为升序，箭头随之翻转。
- **职业筛选**：右侧的职业栏：「全部」和八个职业，选中的职业着蓝色，光标滑到它上面；选中后左边打开它的分支列表（分支的图标和名字，取自游戏的分支表），可以再选一个分支；点列表外的地方收起分支列表。「收起」把职业栏折成右上角的小标签，标签上写着选中的职业或分支。
- **稀有度筛选**：排序栏的第三项改为「稀有度筛选」，点开后排序面板从右边滑入，一行一个星级（6 星到 1 星），可以多选，不选为全部；有筛选时这一项显示为选中样式。点关闭、点面板外或页面的返回收起面板。
- **选择**：点一张卡把它加到这一顺位的末尾，卡上显示它的序号；再点一次取消，后面的序号前移；满了以后提示「最多选择 N 名干员」。另一顺位里的干员卡上显示「编队内已选择」和那个顺位的名字，选它会把它移到这一顺位。「清空选择」清空，「确认」保存（box 里没有的干员以满练度加入 box），返回不保存。
- **详情**：左侧显示最后点过的干员：名字、拉丁字母代号、等级与这一阶段的满级、分支图标；生命、攻击、防御、法术抗性、部署费用、阻挡数和再部署时间、攻击间隔（秒）；这一阶段的攻击范围；「技能」页签列出各技能的图标、名字、技力消耗与初始技力、等级或专精标记、标签（技力回复方式、触发方式、持续时间）和这一等级的说明（数值已填入，游戏的标记按游戏的颜色），精英化阶段不够的技能上锁并写明解锁阶段；「分支+」页签显示分支的图标、名字、特性说明和当前练度下的天赋（还没解锁的显示解锁条件）。还没点过干员时显示「轻触右侧干员以查看详情」。
- **动画**：打开时播放选择页的进场片段（左侧面板、排序栏、列表和底部按钮依次滑入淡入），接着是筛选展开的片段（列表让出职业栏的位置）；职业栏的折叠与展开、分支列表的打开与关闭各播放它们自己的切换片段；职业栏的光标滑向选中的职业；排序面板滑入滑出。
- 列表只建出视野里的几列卡片，滚动时换上对应的干员，左右留出其余各列的位置，所以几百名干员也不卡。
- 素材的界面包里没有这一页时，「快捷编队」提示改用页面自己的干员 box。

- 来源：界面、节点与片段取自界面包（主游戏的 `dyn_char_select_state`、`dyn_panel_char_selection_card`、`dyn_panel_char_sort_custom`、`dyn_char_sort_filter_panel`、`profession_filter` 等，通用干员卡 `panel_char_card` 与它按稀有度换的图）；分支名取自 uniequip_table.json 的 `subProfDict`；技能名、特性说明、代号取自训练数据（引擎 干员-2、干员-3）；各星级的满级为游戏规则（与 页面-2 的满练度一致）；用排序栏的自定义排序位做稀有度筛选是设计决定（原版的筛选面板只有职业筛选）；打开时的状态、遮挡、排序面板的移动、列表顺序、经验环与属性的写法为推断 INF-0028；技能标签的颜色为推断 INF-0029

### 页面-10 主机的 mod

- **取得**：房间页和对局页开始绘制之前，从主机读列表（站点-7），逐个取得并核对数据文件，做出和主机相同的内容来源（引擎 mod-10）；对局页的后台线程同样从主机取得。读不到时用官方内容，对局的内容哈希与主机不同，进不了对局（引擎 同步-10）。
- **干员**：干员 box、快捷编队的干员选择页、房间里的名字和对局的卡片都用这份内容的干员名单和记录，mod 新加的干员和官方干员一样出现；mod 改过的干员按改过的记录显示。
- **外观**：mod 新加的干员用 `look` 写的那名官方干员的头像、半身像、立绘、战斗模型、技能特效和语音（引擎 mod-11）。
- **标记**：主机装了 mod 时，房间页顶栏和对局页左上角（「测试中」之下）显示「装了 mod：」和每个 mod 的 id 与版本，按加载顺序。
- 新加的关卡还没有大厅入口。

- 来源：设计决定，见引擎 ADR 0064（玩家不自己装 mod，从主机取得同一份；装了 mod 的对局加标记）
